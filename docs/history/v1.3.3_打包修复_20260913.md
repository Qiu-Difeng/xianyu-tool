# v1.3.3 打包修复 — 源码文件丢失导致 NoneType 错误

## 目标
修复用户运行工具时报 `'NoneType' object is not subscriptable` 错误

## 根因
`XianyuTool.spec` 的 `datas` 列表只包含 `gui_embed.html`、`wallpaper.jpg`、`cacert.pem`，**没有包含核心源码文件**（xianyu_tool.py、module1_parser.py、module3_copywriter.py、watermark_cleaner.py、anti_detect.py）。

PyInstaller 打包后 `_internal` 目录里缺少这些文件，`xianyu_gui.py` 运行时 `from xianyu_tool import run` 失败，导致后续调用返回 None，前端访问 None 的属性触发 `'NoneType' object is not subscriptable`。

## 修复
在 `XianyuTool.spec` 的 `datas` 列表中添加5个源码文件：
```python
datas = [
    ('gui_embed.html', '.'),
    ('wallpaper.jpg', '.'),
    ('cacert.pem', '.'),
    ('xianyu_tool.py', '.'),
    ('module1_parser.py', '.'),
    ('module3_copywriter.py', '.'),
    ('watermark_cleaner.py', '.'),
    ('anti_detect.py', '.'),
    ('xianyu_icon.ico', '.'),
]
```

## 验证
- PyInstaller 打包成功（exit code 0）
- `_internal` 目录下确认存在全部5个源码文件
- `import xianyu_tool; import module1_parser; import module3_copywriter; import watermark_cleaner; import anti_detect` 全部通过
- NSIS 安装包编译成功（144.3MB）
