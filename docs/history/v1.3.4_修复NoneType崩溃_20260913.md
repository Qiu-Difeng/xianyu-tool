# v1.3.4 修复API Key未配置导致NoneType崩溃

## 日期
2026-09-13

## 问题描述
用户安装v1.3.3后运行工具，报错 `处理失败: 'NoneType' object is not subscriptable`

## 根因分析
1. `module3_copywriter.py` 的 `API_KEY` 从环境变量 `ZHIPUAI_API_KEY` 读取
2. 打包后exe运行时用户电脑没有此环境变量
3. `API_KEY` 变成占位符 `"在此填入你的智谱API Key"`
4. `CLIENT` 变成 `None`
5. `call_glm()` 调 `CLIENT.chat.completions.create()` 抛异常
6. `_run_copywriting` 线程异常，`copy_result` 没有 `data` 键
7. `copies = None`
8. `copies["v1"]` → `'NoneType' object is not subscriptable`

## 修复内容
| 文件 | 修改 |
|------|------|
| module3_copywriter.py | API Key多级查找：环境变量→sys._zhipuai_key→api_config.json→占位符 |
| module3_copywriter.py | call_glm加CLIENT None检查，抛RuntimeError带友好提示 |
| module3_copywriter.py | 顶部加import sys |
| xianyu_tool.py | copies为None时防御性处理（三版本返回空字符串）|
| xianyu_tool.py | 打印文案字数时加None检查 |
| XianyuTool.spec | datas加入api_config.json |
| .gitignore | 排除api_config.json防Key泄露 |
| installer.nsi | 版本号改1.3.4 |
