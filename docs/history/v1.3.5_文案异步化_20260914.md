# v1.3.5 文案异步化优化

## 目标
用户要求：文案单独后台跑，先把其他模块结果显示出来，不要干等。

## 改动内容

### xianyu_tool.py
- `run()` 不再 `copy_thread.join()` 等文案完成，直接返回图片+去水印结果
- 文案线程改为daemon，后台自动跑完自动保存到 copies/copies.json
- 新增全局变量 `_copy_thread` / `_copy_result` 供GUI轮询
- 新增 `is_copywriting_done()` 和 `get_copywriting_result()` 函数
- 文案线程内自动 `save_copies()` 写文件

### xianyu_gui.py
- 新增 `check_copy_status(output_dir)` 方法，供前端轮询文案是否完成

### gui_embed.html
- 文案Tab初始显示"文案后台生成中，预计30-60秒..."（带旋转动画）
- 新增 `startCopyPolling(outputDir)` 每3秒轮询一次
- 文案完成后自动渲染V1/V2/V3，日志区提示"文案生成完成"
- 超时保护5分钟

## 效果对比

| 指标 | 改之前 | 改之后 |
|------|--------|--------|
| 主流程返回 | 101.6秒 | **45.0秒** |
| 图片+去水印显示 | 等101秒 | **45秒就能看到** |
| 文案完成 | 101秒一起出 | 后台约72秒自动弹出 |
| 用户体验 | 干等80秒 | 先看图片，文案好了自动加载 |

## 测试结果
- 主流程：模块1解析36.2秒 + 模块2下载1.0秒 + 模块3a去水印7.8秒 = 45秒
- 文案后台：V1 1718字 / V2 1444字 / V3 515字，72秒完成
- copies.json自动保存成功
