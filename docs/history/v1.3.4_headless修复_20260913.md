# v1.3.4 headless修复 - 2026-09-13

## 问题
- 用户安装v1.3.3后报 `处理失败: 'NoneType' object is not subscriptable`
- 根因1：打包spec漏源码文件（v1.3.3已修复）
- 根因2：API Key未配置导致文案生成失败链路（v1.3.4已修复）
- 根因3：**headless模式被闲鱼检测**，已登录快速路径用 `headless=True` 启动Chromium，闲鱼拒绝返回数据，导致标题/价格/卖家全空

## 修复内容

### 1. headless改窗口移屏外
- `launch_chrome_debug` 新增 `hide_window` 参数
- `hide_window=True` 时加 `--window-position=-32000,-32000` 把窗口移到屏幕外
- 已登录时不再用 `headless=True`，改用 `hide_window=True`（非headless但不可见）
- 闲鱼无法检测非headless浏览器，数据正常返回

### 2. else分支error设置bug
- 第415行 `else: result["error"] = "登录后仍未能获取商品数据"` 逻辑反了
- 拿到数据时走else设了error，没拿到时不设
- 改为两次 `if not detail_api_body:` 检查
